First-time SWD bootstrap

  1. Use the board’s J5 six-pin TC2030 footprint with a TC2030-IDC cable and a 3.3 V compatible SWD probe.
  2. J5 is routed to the Nordic module: pin 1 is +3.3 V, pin 2 SWDIO, pin 3 UWB_nRESET, pin 4 SWCLK, pin 5 GND, and pin 6 is not connected. Confirm the cable orientation against the Rev.C schematic before powering the probe.
  3. Download the combined first-time Rev.C bootstrap HEX. Install it with Nordic nrfutil device program or SEGGER J-Link. It programs the Nordic module only; it does not flash the ESP32-S3.

Install the current Nordic command-line tool and its device command using the official nRF Util installation guide, then run:

# Install Nordic CLI tooling, then list connected debug probes
nrfutil install device
nrfutil device list

# Set this path to the downloaded combined bootstrap HEX. Its HEX records
# omit FDS, UWB calibration, MBR parameter, and backup-settings pages.
nrfutil device program \
  --firmware revc-apple-ni-swd-bootstrap.hex \
  --serial-number <J-Link-serial-number> \
  --options chip_erase_mode=ERASE_RANGES_TOUCHED_BY_FIRMWARE,verify=VERIFY_READ,reset=RESET_PIN

This lab bootstrap uses range erase and its HEX contains no records for FDS at 0x63000–0x64FFF, UWB calibration at 0x7B000–0x7CFFF, MBR parameters at 0x7E000, or the settings backup page. It writes bootloader settings at 0x7F000. Confirm the physical probe target and cable orientation before programming.
